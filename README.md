# Social Intelligence @ UT-Vision

Project hub for social intelligence research at UT-Vision Lab, The University of Tokyo.

Live site: https://ut-vision-social.github.io/

Figures are from the respective papers. To add a project, copy one `<article class="paper">` block in `index.html`, add its figure to `images/` (1200px wide WebP), and add a seat to the `SEATS` list in the script at the bottom.
